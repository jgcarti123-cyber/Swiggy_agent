# Screenshot shot list

Four screenshots, referenced from the main `README.md`. Reproduce each exactly as below, crop to just the relevant panel (not the full OS window), save as PNG into this folder with the exact filename shown.

Before shooting: the saved delivery address label is currently set to a placeholder ("Demo Home") instead of the real one, specifically so it's safe to appear in these screenshots. Don't change it back until all four are captured.

## 1. `insta-nt-brand-picker.png`
1. Open Insta-nt, start from a fresh/empty chat (use "Clear cart" first if the cart has leftover items you don't want visible, or just crop them out).
2. Type `add milk` and send.
3. Wait for the brand question to render (e.g. "Which brand — Amul, Mother Dairy, ...?").
4. Click one brand.
5. Screenshot the product grid that appears, with the brand question still visible above it if it fits in one frame — this is meant to show the whole guided flow (question → cards) in one shot.
6. Crop to the chat panel only.

## 2. `insta-nt-explain.png`
1. On any product card in a grid (the milk grid from step 1 works), click the ℹ️ icon on the product photo.
2. In the Explain modal, ask a real nutrition/health question — the one already verified live: **"is this good for a diabetic?"** on Amul Taaza Milky Milk produced a clean grounded answer with specific numbers (2.35g/100ml, 4.7g/200ml sugar) and 3 source links.
3. Wait for the answer to render with its source citations.
4. Screenshot the modal. If the cart panel is visible behind it (not covered by the modal), leave it in frame — it adds context.

## 3. `insta-nt-recipe.png`
1. Start a new message: **"order things for making biryani"**.
2. Wait for the ingredient checklist to render.
3. Confirm the "🔎 Based on real recipes from the web" note with numbered source links is visible above the ingredient list.
4. Screenshot the full checklist (scroll/crop so the grounding note and at least 8-10 ingredients are visible in one frame).

## 4. `insta-nt-cart.png`
1. With a handful of real items in the cart (from steps above, or add 3-4 more so it doesn't look empty), open/expand the live Cart panel.
2. Screenshot the cart panel showing item rows with quantity steppers, item total, and "to pay".
3. Crop to just the cart panel.
